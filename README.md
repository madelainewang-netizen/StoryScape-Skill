# StoryScape Skill v3.2

面向策划者的地方文化与实景互动剧本创作 Skill。

## 内容

- `create-immersive-mystery/SKILL.md`：生成流程、叙事与互动规范、场地及资源边界。
- `create-immersive-mystery/references/production-contract.md`：同源资源对象、交付约定与测试用例。

## 使用方法

将 `create-immersive-mystery` 整个目录放入所用 AI 工具支持的技能目录，或将两个文件一并提供给支持文档输入的模型，要求按规范创作。具体加载方法以所用工具为准。

输入地点及固定顺序、地方资料、玩家情况、体验时长、真人 NPC 配置与本次实际选用的设备。默认生成三个故事概览，选定后展开；也可明确要求完整测试剧本。

## 主要设计

- 结合地方资料，区分史实、原创与待核现场条件。
- 简单玩家身份与具有吸引力的目标。
- 连贯故事正文、开放式 NPC 互动和明确的玩家任务。
- 严格遵守本次设备、人员、空间与物料条件。
- 同源组织故事与资源，检查信息揭示、分支、物料交接及复位。

## 版本与使用边界

版本号来自原始 Skill 的 metadata，本次发布保留原文件内容。此仓库提供创作规范，不包含大模型 API 服务、前端或已部署的硬件功能。测试用例用于检查生成结果，不代表已通过真人试玩或现场部署验证。
